# AGENTS.md

Instructions for OpenAI Codex CLI working in this coding standards repository.

## Environment

Sandboxed container. No interactive commands. Use non-interactive flags.

## This Repository

This is a **coding standards repository** — Markdown docs, bash scripts, and agent configs. Not an application.

## Key Commands

- `make test-scripts` — Validate bash script syntax
- `make test` — Run all tests (scripts + bootstrap + gh-task + safe-setup + linter + generator)
- `make lint` — Lint markdown files
- `make generate-standards-lists` — Regenerate the standards lists below from `standards/` (CI fails on drift)
- `make check-agent-configs` — Verify agent configs are current and reference only existing standards
- `bash -n scripts/<name>.sh` — Check individual script syntax

## Conventions

- Conventional Commits: type(scope): subject
- Standards numbering: category-based prefixes (arch-XX, lang-XX, proc-XX, sec-XX)
- Shell scripts must pass `bash -n` syntax validation
- When modifying shared standards in core-standards.md, verify agent configs stay aligned
- Never edit between `<!-- BEGIN GENERATED -->` / `<!-- END GENERATED -->` sentinels; change `standards/` or `standards/catalog.tsv` and run `make generate-standards-lists`

## Architecture

Standards documents in `standards/` organized by category. Agent base templates in `standards/agents/`. Content blocks in `standards/shared/blocks/`. Document templates (ADR, spec, plan, design pass, verification) in `templates/docs/`. Scripts in `scripts/` are all bash; lint-check modules in `scripts/lint-checks/`.
