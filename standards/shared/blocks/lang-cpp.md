C++20 baseline (`target_compile_features(... cxx_std_20)`, `CMAKE_CXX_EXTENSIONS OFF`); C++17 floor only where a platform toolchain lags, stated in the README matrix and an ADR with a CI lane on the floor compiler.
Toolchain matrix: Clang 16+ / Apple Clang (Xcode 15+), GCC 12+, MSVC 19.36+ (VS 2022). CI builds on every compiler the README lists.
Build with CMake 3.25+ and Ninja through committed `CMakePresets.json` presets (`dev`, `ci`, `ci-asan-ubsan`, `ci-tsan`, `release`); targets only (`target_*`), no globals, no `file(GLOB)` for sources, `compile_commands.json` exported.
Warnings on an `INTERFACE` target every target links (`-Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion -Wnon-virtual-dtor -Wold-style-cast ...`; `/W4 /permissive- /utf-8` on MSVC). Warnings-as-errors ON in the `ci` preset (`CMAKE_COMPILE_WARNING_AS_ERROR=ON`), OFF by default locally; never hard-code `-Werror` without an `option()` guard.
Format with `clang-format` (root `.clang-format`, `--dry-run --Werror` in CI). Lint with `clang-tidy` (committed `.clang-tidy`, `WarningsAsErrors: '*'` in CI); suppressions are `// NOLINT(check): reason`, never bare.
Naming: `snake_case` functions/variables/namespaces/files, `PascalCase` types, `snake_case_` private members, `kPascalCase` constants and enumerators, `enum class` always, `[[nodiscard]]` on status and resource returns.
Headers: `#pragma once`, self-contained, forward-declare, no `using namespace` at namespace scope, no STL types in a shared-library export signature, PIMPL across shared-library boundaries. C++20 modules only internal to one build tree with every matrix compiler on CMake 3.28+ and an ADR.
Ownership: no naked `new`/`delete`; `std::unique_ptr` default, `std::shared_ptr` justified in a comment; borrow with `std::span`/`std::string_view`; rule of zero; destructors and moves `noexcept`.
Errors: `expected<T, Error>` (`std::expected` on C++23, `tl::expected` alias on C++20) for expected failures; status enums (`0` = OK, stable codes) at every `extern "C"` boundary; exceptions only for bugs and exhaustion inside the core, never across the C ABI, a thread or a callback; `catch (...)` only in the facade.
C ABI (`bindings/c/`): `extern "C"` C99 header, opaque handles, fixed-width scalars, UTF-8 `const char*`; every `create` has one matching `destroy` and only it frees; no allocator ownership crosses (caller-provided buffers + `required_len`); borrowed pointers expire on the next mutating call or destroy; null handles tolerated (`destroy(nullptr)` no-op); engine calls serialised when the engine demands it; every function body wrapped in `try`/`catch` mapping to a status with a thread-local `snprintf`-bounded last-error buffer; `-fvisibility=hidden` plus an export macro; `<prefix>_abi_version()`. Wrapper side: arch-07 §3.
Concurrency: `std::jthread`/`std::stop_token`, no `detach()`, shared state locked or atomic, Clang thread-safety annotations, TSan lane mandatory for anything that spawns a thread.
Tests: GoogleTest or Catch2 via CTest (`ctest --output-on-failure`), 95% coverage / 100% domain, conformance vectors in `tests/conformance/` shared with wrappers, libFuzzer targets for every parser.
Sanitizer lanes on every PR run the test suite: ASan+UBSan (`-fsanitize=address,undefined -fno-omit-frame-pointer -fno-sanitize-recover=all`) and a separate TSan build; hardened libstdc++/libc++ assertions in Debug.
Cross-platform: UTF-8 sources without BOM, `.editorconfig` + `.gitattributes` (`* text=auto eol=lf`), `/utf-8` on MSVC, no `wchar_t` in portable APIs, `std::filesystem::path`, fixed-width ints and `std::endian` for anything serialised, OS `#if`s only in `src/platform/`, `WIN32_LEAN_AND_MEAN`/`NOMINMAX` before `windows.h` (never in a public header).
Dependencies: manifest + lock (`vcpkg.json` + `builtin-baseline`, `conan.lock`, or `FetchContent` pinned to a full SHA), `osv-scanner` in CI, license allow-list.
Vendored and inherited code stays verbatim under `third_party/<name>/` with `UPSTREAM.md`: own `.clang-format` with `DisableFormat: true`, `SYSTEM` includes, `COMPILE_WARNING_AS_ERROR OFF`, local fixes as patches, no mass reformat or drive-by modernisation; coverage scope `layer: inherited`.
Security: no `gets`/`strcpy`/`sprintf`/`system`/`rand()`-for-secrets, `std::from_chars` over `atoi`, hardening flags (`-D_FORTIFY_SOURCE=3 -fstack-protector-strong -fPIE -Wl,-z,relro,-z,now`; `/GS /guard:cf /DYNAMICBASE`), OS CSPRNG for secrets, fuzz every untrusted parser.
