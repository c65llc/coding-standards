# Global egress allow-list (arch-09 §4, Global Layer).
#
# Baseline destinations every containerized dev environment needs. Ships with the
# standards. Projects add their own entries in proxy/project-whitelist.txt — do
# not edit this file per-project.
#
# One host per line. '#' comments and blank lines are ignored. A leading "*."
# allows every subdomain (e.g. "*.example.com"); nothing else is a wildcard.
# setup-proxy.sh rejects anything that is not a hostname, so a stray "*" or a
# URL can never widen the list, and the egress sidecar matches entries as
# whole-host globs: "github.com" does not match "github.com.evil.example".
